# 达芬奇 D-LogM 调色流程

这套流程是我用 Osmo Nano 拍 D-Log M 素材时沉淀下来的：节点顺序固定、参数给基准值、每步都有验收标准，最后导出 33 点 cube LUT，AE 和剪映专业版直接复用。

## 适用范围

- 素材：DJI Osmo Nano，色彩空间 D-Gamut，伽马 D-Log M，室内场景。
- 目标：Rec.709 交付；导出 33 点 cube LUT 供 AE / 剪映专业版复用。
- 前提：D-Log M 无达芬奇内置 CST 伽马预设，Log 还原依赖大疆官方 `DLog-M to Rec709 Vivid.cube`；CST 仅处理色域转换。

## 节点链

1. 降噪（Motion Effects）
2. CST 色彩空间转换（D-Gamut → Rec.709）
3. 大疆官方还原 LUT
4. 一级校正（白平衡、曝光、黑白场）
5. 创意风格调色（全局，无蒙版）
6. 导出 LUT

顺序固定，别换顺序：降噪必须在最前，CST 紧随其后，还原 LUT 在 CST 之后。

## 节点 1：降噪

- 适用版本：达芬奇 Studio（免费版该面板不可用）。
- 操作：新建串行节点（`Alt+S`）→ 打开 Motion Effects 面板。
- 参数：
  - Temporal NR：Frames 2；运动估计 Better；运动范围 Medium；Luma Threshold 18；Chroma Threshold 30。
  - Spatial NR：Mode Better；Radius Small；Luma Threshold 10；Chroma Threshold 25。
- 校验：画面放大 100% 观察；`Ctrl+D` 开关节点 A/B 对比。
- 达标：暗部无可见噪点；木纹等纹理未糊化；运动区域无鬼影。参数为基准值，按素材光线微调。

## 节点 2：CST 色彩空间转换

- 位置：特效库 → Resolve FX → 色彩 → 色彩空间转换（CST）。
- 操作：新建串行节点，将 CST 拖至节点，在右侧检查器设置：
  - 输入色彩空间：DJI D-Gamut
  - 输入伽马：None
  - 输出色彩空间：Rec.709
  - 输出伽马：Rec.709 Gamma 2.4
- 校验：开关节点对比画面色偏。
- 达标：四项参数与上表一致；画面无明显偏色，不呈灰绿色调。

## 节点 3：大疆官方还原 LUT

- LUT 文件路径（Windows，全用户共享）：
  `C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\LUT`
  在 LUT 目录下新建 `DJI` 文件夹，放入 `DLog-M to Rec709 Vivid.cube`，重启达芬奇。
- 操作：新建串行节点 → 节点右键 → LUT → 3D LUT → 选择该 LUT。
- 达标：画面恢复常规观感（白墙接近纯白、曝光正常）。本节点只做还原，不追求风格。

## 节点 4：一级校正

- 调色工具位于调色页面下方（色轮 / 曲线 / 色阶标签）；右侧检查器用于调整 OFX 插件参数。
- 白平衡：一级-校色轮 → 白平衡吸管，点击画面中纯白物体（白墙）；必要时手动微调色温（±200K 内），色调少动。
- 黑白场与曝光：曲线 → RGB 主曲线。黑场右移轻抬暗部（过度拉升会放大噪点）；白场左移压制高光（优先保留窗户细节）；中间点控制整体亮度。
- 饱和度：±5 以内微量修正，不在此阶段做风格化。
- 示波器：调色页面预览窗口右键 → 显示示波器（剪辑页面该选项禁用）。

| 示波器 | 判定标准 |
|---|---|
| 波形图 | 高光不顶满 1023；暗部不整片贴 0 |
| 矢量图 | 白墙像素位于中心附近（中性白） |
| 直方图 | 最右侧不顶死在 1023 边缘 |

- 达标：白墙中性、高光无裁切、暗部无死黑、无噪点爆发；开关节点后无风格化痕迹。

## 节点 5：创意风格调色

- 约束：仅全局调色，禁止窗口、蒙版、限定器、HSL 选区（影响 LUT 导出正确性）。
- 一级-校色轮：中灰极轻微暖调（白墙不可变黄）；阴影极轻微冷蓝。
- 曲线：平缓浅 S 型（中间微抬、高光微压、暗部微抬），不做强对比。
- 色相饱和度：全局饱和度 +3 ~ +8（不超过 +10）；橙色通道 +2 ~ +4（温润木色）；色相滑块不动。
- 达标：开关节点后白平衡与曝光不变，仅氛围变化；矢量图白墙仍居中；波形图保持 0–1023 区间。

## LUT 导出

- 选中最后一个节点（节点 5）→ 预览窗口右键 → 生成 LUT。
- 参数：尺寸 33 点；格式 `.cube`；范围全范围 0–1023。
- 应用：
  - AE：颜色查找效果加载该 cube；素材先完成 DLogM 还原再叠加。
  - 剪映专业版：调节 → LUT → 导入并应用；强度 80–100。该 LUT 已含还原，勿再叠加大疆官方还原 LUT；手机剪映不支持外部 cube。

## 预设保存

- 整套节点：预览窗口右键 → 抓取静帧 → 画廊面板（`Ctrl+G`）→ 左侧右键添加共享静帧集（PowerGrade）→ 将静帧拖入。
- 调用：右键静帧缩略图 → 附加节点图（追加，不覆盖原节点）/ 应用调色（替换全部节点）；批量选中素材后右键可一次套用。
- 单节点：节点右键 → 另存为共享节点（仅保存单个节点）。
- 备份：右键缩略图 → 导出 `.drx` 文件。

## 完成校验清单

- [ ] 节点 1：暗部无噪点、纹理清晰、无鬼影
- [ ] 节点 2：CST 四项参数正确、画面无偏色
- [ ] 节点 3：画面恢复常规观感
- [ ] 节点 4：白墙中性、高光 <1023、暗部不死黑
- [ ] 节点 5：仅全局调色、基础光影未被破坏
- [ ] 导出：末节点选中、33 点、cube、全范围
- [ ] 预设：静帧已存入共享静帧集
