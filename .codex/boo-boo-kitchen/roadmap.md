# Roadmap

更新：2026-10-05 · 当前：设计完成，M0 未开始

## 推进原则

按验收推进，不以代码写完为完成。不预先锁定日期：学习与美术耗时在阶段结束后记录，再估算下一阶段。所有任务初始未完成。

依赖：M0 → M1 → M2 → M3 → M4 → M5。正式资产在 M2 尺度稳定后可制作；M6 不阻挡首版。

## M0 — 决策与技术探针

- [ ] 确认首菜、词库、目标英语程度、角色参考与二维角色方向。
- [ ] 原生 Three.js 小练习：相机、几何体、材质、灯光、循环。
- [ ] 核对 R3F/Drei 兼容性，独立路由最小 Canvas。
- [ ] 验证动态加载、StrictMode 重挂载、退出清理。
- [ ] 选实际测试设备与浏览器，记录基线。

交付：最小场景、兼容性记录、确认后的菜谱与资产清单。
验收：未访问游戏时主站无运行时请求；刷新和反复进出无初始化异常。
学习：Scene、Camera、Renderer、Mesh、生命周期。

## M1 — 可操作灰盒

- [ ] 三层构图、四工位、厨房尺度与交互点。
- [ ] 固定镜头与容器适配。
- [ ] 点击检测、合法移动、避障。
- [ ] 持物、放下、满槽反馈。
- [ ] 调试面板显示实例、槽位与命令。

交付：能走动并搬运食材的厨房。
验收：不穿家具，物品仅归属一个位置，不可达和满手有解释。
学习：Raycaster、坐标、向量、delta、对象层级。

## M2 — 词汇与最短操作闭环

- [ ] 选择与可调整的记忆阶段。
- [ ] 传送带、HTML 输入、答案校验与提示。
- [ ] 容量与需求配额、幂等交接。
- [ ] 索取番茄 → 拿取 → 备料台输入 chop → 切块产出。
- [ ] 暂停、输入法、页面隐藏、焦点恢复。
- [ ] 小范围试玩，记录输入与操作切换体验。

交付：第一条可玩的获取/处理流程。
验收：Enter 不重复发货；输入不误移动；错误可恢复；后台不跳步骤。
学习：DOM/Canvas 协作、投影、状态驱动表现。
门槛：节奏不顺先调整题目频率和暂停策略，再做美术。

## M3 — 一道菜完整 MVP

- [ ] 菜谱协议、依赖与输入输出校验。
- [ ] 备料、烹饪、装盘、提交、结算。
- [ ] 新词必考、错词优先、题目串行。
- [ ] 重玩、退出、静音、本地记录与损坏恢复。
- [ ] 验证库存、占用、重复事件、叠加暂停和旧回调。
- [ ] zh/en 界面，答案均为英文。

交付：占位美术下完整的一道菜。
验收：连续三局无锁死/残留，统计准确，错误可继续。
学习：状态机、数据驱动与可验证规则。
门槛：完整闭环稳定后进入正式视觉打磨。

## M4 — 正式美术与性能

- [ ] 角色、场景、工具和首菜资产，登记来源与授权。
- [ ] 验证 GLB 尺度、挂点、精灵透明、遮挡与接地。
- [ ] 动画、特效、声音、减少动态效果。
- [ ] 优化贴图/图集、DPR、材质与阴影。
- [ ] 实测加载和帧耗时，记录预算调整依据。

交付：美术完整候选版、资产清单、性能记录。
验收：正式资产不改变规则，文字与物件清晰，设备达到约定帧率。
学习：模型加载、纹理、透明、动画、GPU 成本。

## M5 — 网站集成与交付

- [ ] 拆分 Edgewise 卡片专用预览，新增厨房轻量入口。
- [ ] 双语项目条目、独立路由、SEO、加载与返回。
- [ ] 重场景初始化避开主站导航动画。
- [ ] 首页/文章/列表无游戏资源请求，Edgewise 无回归。
- [ ] 加载失败、WebGL 不可用、上下文丢失、存储异常。
- [ ] 用户同意后 CU 验证，运行适用 tsc/lint/build。
- [ ] 更新 AGENTS.md 和设计状态，记录限制。

交付：可评审本地首版及验证证据。
验收：主站正常，三次进出无遗留音频/循环，完整玩法与故障恢复通过。
提交/发布：列变更摘要并按仓库要求获得确认；本阶段不自动授权 commit/push。

## M6 — 后续扩展

- [ ] 第二、第三道菜验证数据协议复用。
- [ ] 一个新动作验证工位扩展接口。
- [ ] 按试玩反馈设计限时/火候挑战。
- [ ] 移动端触控、软键盘、横竖屏与性能验收。
- [ ] 可选三维骨骼厨师。
- [ ] 有需要后评估账号同步与间隔复习。

## 风险登记

| 风险 | 验证点 | 应对 |
| --- | --- | --- |
| 学习与范围膨胀 | M0 | 每阶段一个主题，先占位资产 |
| 输入割裂节奏 | M2 | 串行题目、暂停、减少频率 |
| 透明遮挡错误 | M1/M4 | 用代表精灵尽早测试 |
| 收货库存死局 | M2/M3 | 容量、配额与回收补发 |
| 资产制作过慢 | M2 | 尺度稳定后制作，复用动作 |
| 主站加载泄漏 | M0/M5 | 独立入口、禁预取、网络验收 |
| GPU 成本过高 | M0/M4 | 真实设备、分级质量、阶段加载 |
| 菜谱实际硬编码 | M6 | 第二道菜检验协议，收敛抽象 |
