# Boo Boo Kitchen — 设计总览

更新：2026-10-05 · 版本：0.1 · 状态：设计基线，尚未实现

## 项目定位

挂载在 yao.me 实验室的单人浏览器英语烹饪游戏。玩家操控 Yao 的个人形象厨师，用英文向传菜员索取食材，再完成处理、烹饪与装盘。项目同时作为 Three.js 学习实践。

已确定：Three.js 路线、传送带/传菜员/厨师台三层布局、食材与动作英文输入、点击后加载，与主站隔离。

建议基线：固定正交视角、三维厨房配二维手绘角色，正式项目采用 Three.js + React Three Fiber。首道菜暂定番茄炒蛋，角色形式与词库在 M0 确认。

## 设计支柱

1. 英文词汇触发有意义的厨房行为，答对后有明确的场景反馈。
2. 输入与移动互斥，基础模式允许思考，不因打字慢惩罚玩家。
3. 固定视角与小场景，先完成一道菜，再扩展数据和美术。
4. 游戏运行时不进入主站公共依赖，素材按公共场景与菜谱分阶段加载。
5. 每个里程碑交付可玩的结果，并对应一个 Three.js 学习主题。

## 首版范围

桌面优先、点击移动；一名厨师、一名传菜员、一个厨房、一道菜；3–5 种食材与 3–4 个主要动作词。目标每局 3–5 分钟。

完整流程：选择 → 记忆 → 英文索取 → 处理 → 烹饪 → 装盘 → 错词复习。支持暂停、静音、本地词汇记录、加载重试、zh/en 界面。

后续：三道菜、挑战模式、移动端、三维骨骼角色。首版不排入多人、账号同步、真实流体、物理切割、语音识别或厨房编辑器。
